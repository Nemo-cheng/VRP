# 统一实验说明

正式入口为：

```powershell
uv run python experiment/run.py --time-limit 1800
```

快速检查使用：

```powershell
uv run python experiment/run.py --skip-build --time-limit 30
```

三个模型依次为 `vrp_spd`、`vrp_tw_spd` 和 `evrp_tw_spd`。所有模型使用同一个 `jd200_1` 实例，只改变时间窗、电池和充电约束。

指标评估遵循官方求解器语义。路线中的电量状态表示车辆剩余可行驶距离，充电时间按剩余距离增量、单位距离能耗和充电速度计算。最短时间路径中经过但未充电的站点单独计为途经站点。
