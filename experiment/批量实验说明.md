# 批量实验说明

三种子预实验：

```powershell
uv run python experiment/run_batch.py --skip-build --time-limit 60 --seeds 42 43 44
```

正式五种子实验：

```powershell
uv run python experiment/run_batch.py --skip-build --time-limit 300 --seeds 42 43 44 45 46
```

每个模型、随机种子和求解时长使用独立目录。再次执行相同命令时，已完成的任务会自动跳过。

汇总文件包括：

```text
results/batch_metrics.csv
results/batch_metrics.json
results/batch_paired_deltas.csv
results/batch_summary.json
results/batch_summary.md
```

原始路线、运行日志和运行元数据保存在 `results/runs`。该目录不提交到 Git。
